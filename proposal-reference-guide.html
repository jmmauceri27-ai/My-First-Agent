Key Trends & Insights

Service Vehicle Charge is Always Included
$297.50 appears in every proposal with itemized line items. It's the baseline mobilization cost — treat it as a non-negotiable starting point on every job, regardless of size.
Labor: "Crew" vs. "Foreman/Laborer"
  • Crew ($318.75/crew-hr): Used for repair/maintenance work — tree trimming, curb work, pothole repair. Doesn't break out the individual workers.
  • Foreman + Laborer separately: Used for landscape installs where skill differentiation matters (directing planting vs. digging/hauling). Foreman ~$125/hr, Laborer ~$98/hr.
Dumping Charge Scales with Debris Volume
  • Light tree trim: ~$207–$218
  • Site-wide curb repairs + tree trim: ~$930
  • Planting/install jobs: No dumping charge (no significant debris)
Always include if tree work or concrete demolition is involved.
Misc Material vs. Named Material
  • "Misc": Used when materials are incidental — patch concrete, curb paint, pothole mix. Scales $234→$638 with repair scope.
  • Named materials (River Stone, Plant Material, etc.): Used when a specific product is being installed and the client needs to see what they're paying for.
Equipment Rental Triggers
The F550 Crew/Dump Truck was added only when curb repairs spanned the entire site (multiple locations) and concrete debris was heavy. For light tree trims, the standard service vehicle handles hauling. Add equipment rental when: volume of debris is high, concrete work requires a dump truck, or the job spans multiple days.
When to Bundle vs. Itemize
  • Itemize when scope is 1–3 tasks — gives client transparency.
  • Bundle as "Agreement Regular" when scope is 5+ distinct tasks (9 in DV10548051193). The description still breaks out each sub-price so the client sees the math, but the line item is a single number.

Proposal Building Checklist

Question to Ask If YES → Add This Line Item Notes
Is any crew going to the site at all? Service Vehicle & Equipment Charge — $297.50 Always first. No exceptions.
Is this primarily repair/maintenance work (trim, patch, curb)? Labor — Crew @ $318.75/hr Use crew-hours; estimate conservatively and round up.
Is this a landscape install (planting, hardscape, grading)? Labor — Landscape Foreman + Landscape Laborer separately Break out by role so client sees skill differentiation.
Will there be tree cutting or concrete demolition? Dumping Charge Scale up if site-wide; ~$200–$250 for single-tree, $900+ for multi-location concrete.
Are incidental repair materials needed (patch, paint, fill)? Misc Material Use "Misc" for catch-all repair supplies; name specific materials for installs.
Are specific products being installed (stone, plants, grasses)? Named Material line(s) (e.g., River Stone 1"–3", Plant Material) Separate line per distinct product. Gives client transparency.
Is the job site-wide, multi-day, or heavy on concrete debris? Equipment Rental — F550 Crew/Dump Truck Add when standard service vehicle can't handle debris/material volume.
Are there 5 or more distinct scopes on one proposal? Consider Agreement Regular (single bundled line) Still itemize each cost in the Description field so client can see the math.
