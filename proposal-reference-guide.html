Two Distinct Proposal Formats — When to Use Each

Format A — Reactive / Work Order (Simple Itemized)
  • When: Client submits a specific work order or complaint. 1–4 defined tasks.
  • Structure: Cover letter → Line items (Crew, Dump, Misc, Trip Charge) → Acceptance page → Photos
  • Labor: "Crew" at $318.75/hr, or named Foreman + Laborer for installs
  • Materials: "Misc" for repairs; named specific products for installs
  • Always include: Service Vehicle & Equipment Charge ($297.50)
  • Safety items: Flag with "(SAFETY CONCERN)" in the description line — justifies urgency and liability
  • Total range: $2,600–$7,600
  • Examples: DV105480441194, DV105480271195, DV105480251191, DV10548021331
Format B — Site Inspection / Enhancement Proposal (Agreement Regular) NEW
  • When: Site inspection reveals multiple improvement opportunities. 5+ scopes. Proactive upsell.
  • Structure: Cover letter → Existing Site Conditions narrative → Each scope as its own "Agreement Regular" line item → Safety Hazard sections → Optional Enhancement Upgrades → Acceptance → Work order trip report
  • Each line item includes: Named scope title + Scope bullets + Labor (named roles + hours) + Materials list + Equipment list
  • Safety items: Label as "Safety Priority Item" within the line item description
  • Optional upgrades: Always list additional enhancements at the end (LED lighting, irrigation inspection, seasonal flowers, decorative stone) — these become future proposals
  • Total range: $10,000–$22,000+
  • Examples: DV105480301351, DV10548091350, DV10548051193

Key Trends & Insights

Service Vehicle Charge ($297.50) — Almost Always
Appears on every reactive/itemized proposal. The only exception is when labor is billed as a large flat-rate Crew charge that absorbs the trip cost (DV10548021331). When in doubt, include it.
Labor: "Crew" vs. Named Roles
  • Crew @ $318.75/crew-hr: Maintenance/repair — tree trim, curb, pothole. Never named individually.
  • Crew (flat $ bundled): Used on large multi-scope jobs where hours are hard to predict.
  • Foreman + Laborer separately: Landscape installs where role differentiation matters. Foreman ~$125/hr, Laborer ~$98/hr.
  • Named technician types in Format B: "Landscape Technicians," "Asphalt Technicians," "Masonry Technicians" — use the right trade name for the scope.
Dumping Charge Scales with Debris
  • Single light tree trim: ~$207–$218
  • Tree trim + safety concrete repair: ~$282
  • Site-wide curb demolition: ~$930
  • Multi-scope flat-rate job: absorbed into crew charge (no separate line)
  • Format B proposals: disposed as haul-away within each agreement item
Flag Safety Concerns — Always
Two formats for safety flags:
  • Format A: Add "(SAFETY CONCERN)" to the end of the description line — e.g., "Trim tree away from light poles (SAFETY CONCERN)". Justifies urgency and cost.
  • Format B: Label the line item itself as "Safety Priority Item" in the scope heading. List recommended corrective work in bullets. Mention liability exposure in the conclusion.
Safety flagging is how reactive repairs become approved faster.
Format B: Site Inspection Proposal Structure
When a site inspection reveals 5+ improvements:
  • Open with Existing Site Conditions — describe what's there (parking, landscaping, pavement, signage)
  • Each scope = its own "Agreement Regular" line item with: Scope bullets, Labor (role + hours), Materials list, Equipment list
  • Close with Optional Enhancement Upgrades — LED lighting, seasonal flowers, irrigation inspection, decorative stone. These become the next proposal.
  • Attach site inspection work order trip report
State Tax Rates — Build Into Every Quote
  • New Hampshire: 0% — no sales tax line
  • Massachusetts: 6.25%
  • New York (general): 8.125%–8.875% depending on county
Tax rate affects the "Estimate Total" significantly on large jobs. Confirm the county rate before finalizing.
Misc Material vs. Named vs. Absorbed
  • "Misc": Incidental repair supplies — patch, paint, fill, concrete. Scales with repair scope ($234–$638 reactive; $2,010 for large multi-scope).
  • Named materials: When a specific product is installed — River Stone, Plant Material, Grasses. One line per product.
  • Absorbed in Format B: Materials listed inside each Agreement item's description; no separate top-level material line.
Asphalt Work — Standard Components
Whenever asphalt repair is in scope:
  • Labor: 2 Asphalt Technicians + 1 Foreman (Format B), or bundled Crew (Format A)
  • Materials: Hot rubber crack filler, asphalt patch, sealcoat, traffic control
  • Equipment: Crack sealing machine, plate compactor, asphalt saw, blowers, safety barricades
  • Always label as "Safety Priority Item" — cracking creates trip/vehicle damage liability
Turf / Bed / Shrub — Standard Components
  • Bed Restoration: Mulch, weed control, bed edgers, blowers, wheelbarrows. 2 techs + 1 crew leader × 6–8 hrs.
  • Turf Restoration: Grass seed, starter fertilizer, topsoil, broadcast spreaders, aerator/overseeder. 2 techs × 5 hrs.
  • Shrub/Hedge: Hedge trimmers, pole saws, chainsaws, dump trailer. 2 techs + 1 crew leader × 4–6 hrs.
  • These three often appear together in Format B site proposals.

Proposal Building Checklist — Start Here

Question to Ask If YES → Add / Do This Notes
How many scopes does this job have? 1–4 tasks → Format A (itemized). 5+ tasks → Format B (Agreement Regular per scope) or bundled single Agreement. This is the first decision. Everything else follows from it.
Was this triggered by a site inspection? Use Format B. Start with Existing Site Conditions narrative. End with Optional Enhancement Upgrades. Attach the work order trip report as an exhibit.
Is any crew going to the site at all? (Format A) Service Vehicle & Equipment Charge — $297.50 Always first. Only omit if absorbing into a flat crew rate.
Is the work maintenance/repair? (trim, patch, curb, pothole) Labor — Crew @ $318.75/hr Estimate hours conservatively; round up. 6=light, 8=moderate, 10=full day, 12=heavy.
Is the work a landscape install? (plants, hardscape, grading) Labor — Landscape Foreman + Landscape Laborer on separate lines Foreman ~$125/hr directs; Laborer ~$98/hr does physical work. 2:1 ratio typical.
Will there be tree cutting or concrete demolition? Dumping Charge ~$207–$282 for single-tree jobs; scale up to $930 for site-wide concrete demolition.
Is the job site-wide, multi-day, or heavy on concrete debris? Equipment Rental — F550 Crew/Dump Truck (~$239/day) Add when standard service vehicle can't handle debris volume. Use "Equipment" (generic) for varied multi-type equipment.
Are incidental repair materials needed? (patch, paint, fill, concrete) Misc Material Scales $234–$638 for repairs; $2,010 for large multi-scope. Use named materials for specific installs.
Are specific products being installed? Named Material lines (River Stone 1"–3", Plant Material, Grasses, Sod, Mulch) One line per distinct product. Client should be able to see exactly what they're buying.
Does any scope involve safety risk? (structure scraping, loose railing, trip hazard, sightline) Format A: Add "(SAFETY CONCERN)" to that description line. Format B: Label line item "Safety Priority Item," describe liability risk in body. Safety flagging speeds client approval and protects against future liability disputes.
Does the job involve asphalt? Include: crack sealing machine, plate compactor, asphalt saw, safety barricades in equipment. Materials: hot rubber crack filler, asphalt patch, sealcoat. Always mark as Safety Priority. 2 asphalt techs + 1 foreman standard team.
Is this a Format B proposal? Does it end there? Add an Optional Enhancement Upgrades section at the close: LED lighting, seasonal flowers, irrigation inspection, decorative stone, signage repainting. These become the next proposal. Always leave a hook for the next visit.
What state is the job in? Apply correct tax: NH = 0%, MA = 6.25%, NY = 8.125–8.875% (verify county) Tax on a $10K job swings by $800+ between NH and NYC. Always confirm before sending.
